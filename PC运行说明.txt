Gesture Lab V2 - Windows 完整运行包

一、首次运行
1. 解压整个 ZIP，不要只在压缩包预览中启动。
2. 电脑需安装 Python 3.10 或更高版本。
3. 双击“启动控制台.bat”。
4. 首次启动会自动安装 numpy 与 h5py，需要保持联网。
5. 浏览器自动打开 http://127.0.0.1:8765/
6. 实验期间请勿关闭命令行窗口。

二、浏览器建议
- 推荐 Microsoft Edge 或 Google Chrome。
- 摄像头权限请选择“允许”。
- 启用摄像头时浏览器会再弹一次“控制摄像头平移、倾斜和缩放”，也必须选“允许”。
  不允许的话浏览器不会开放变焦控制，程序无法锁死镜头，画面会自动变焦。
- 被试扩展屏可由主试控制台打开。

三、摄像头设置（海康 U62 Pro，首次使用必做）
相机固件自带的“AI 人像居中/人脸跟踪”会在相机内部裁切画面，
人一动整幅画面就跟着平移，浏览器看不到也关不掉，必须先用海康 HIK IN
上位机关闭（设置写入相机，之后长期有效）：

1. 下载 HIK IN：海康威视官网 → 服务支持 → 工具专区（hitools）。
2. 在 HIK IN 中对每台摄像头关闭：
   - AI 人像居中 / 人脸跟踪 / 自动构图
   - AI 美颜
   - 对焦模式改为手动，固定视场角档位
   - 白平衡 / 亮度 / 对比度 / 饱和度改为手动固定值
3. 回到控制台“视频与设备”页启用摄像头。程序会自动锁定对焦、变焦、
   曝光、白平衡，并在录制期间持续巡检，被相机复位会自动重新锁定。
4. 点“追踪自检”，人在镜头前左右走动 5 秒（相机与背景保持静止）。
   显示“通过”说明 AI 人像居中确实已关闭；显示“未通过”请回 HIK IN 再检查。

每段录制的镜头锁定状态与漂移记录会写入 workflow_events 日志，事后可核查。

四、数据位置
每轮实验记录位于：

sessions/<被试编号>/<Session编号>/

每个记录段结束后生成：

<session_tag>_capture_NN.h5

HDF5 使用 xgr.capture/1.0，结构要求见：

docs/Capture HDF5 数据格式规范.md

包内程序在发布 HDF5 前会检查：
- 根 Schema 和必填 Group
- 三个固定摄像头通道
- Watch 原始 CSV 与 Accel 标准视图
- Events 与 Integrity 平行数组长度
- 所有原始视频/CSV 的 SHA-256
- 禁止写入 /Users/... 或 Windows 盘符绝对路径

如果视频或手机日志缺失，文件仍会生成，但 /meta/status 会标记为 incomplete。
已经发布的 Capture 不会被覆盖；重录应开始新的记录段。

五、更新
保留 sessions 文件夹。收到更新 ZIP 后，双击“更新程序.bat”并按提示选择更新包。
